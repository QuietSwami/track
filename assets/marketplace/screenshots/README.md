# Screenshots

Real Calendar screenshots are intentionally excluded from Git because they can contain private account or scheduling information.

For a future Marketplace submission, create screenshots with a dedicated demonstration account and synthetic calendars and events. Accepted full-bleed PNG sizes are 1280×800, 640×400, and 2560×1600. Keep the files locally in this directory for `npm run publication:check`, then upload them directly to the Marketplace rather than committing them.
