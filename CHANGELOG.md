# Changelog

All notable changes to Track! - Time Tracker for Google Calendar are documented here.

## 1.1.0 — 2026-09-14

- Renamed Project Time to Track! - Time Tracker for Google Calendar.
- Preserved existing saved settings and view state for seamless upgrades.

## 1.0.0 — 2026-09-09

- Added weekly and monthly scheduled-time summaries by project calendar.
- Added period navigation, Today, Refresh, and persistent user settings.
- Added per-project detail cards with daily breakdowns, averages, busiest day, and longest and shortest named activities.
- Added recurrence expansion, boundary clipping, timezone and DST handling, configurable exclusions, and overlap disclosure.
- Added user-scoped caching and confirmed in-product deletion of saved add-on data.
- Added dependency-free calculation tests and source/manifest verification.
- Prepared the project for self-installation from source under the MIT License.
