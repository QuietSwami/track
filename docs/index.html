Project Time

Understand scheduled time by project, directly in Google Calendar.

Privacy Terms Support

One calendar, one project

Choose the calendars that represent your projects. Project Time totals qualifying event durations for the selected week or month and presents each calendar using its existing name and color.

Useful scheduling statistics

Review total scheduled time, project shares, daily breakdowns, event counts, busiest days, average durations, longest and shortest named activities, and overlap notices.

Private by design

Project Time runs entirely within Google Apps Script and Google Calendar. It has no external application server, database, advertising, analytics, or AI processing. It only requests read-only Calendar access and never creates, changes, or deletes events.

Project Time is an independent product and is not affiliated with or endorsed by Google.
