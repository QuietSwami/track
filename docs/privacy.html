Who operates Project Time

Project Time is provided by Francisco Mendonça. Privacy questions can be sent to franciscoabmendonca@pm.me.

Data the add-on reads

After a user grants permission, Project Time reads accessible Google Calendar metadata such as calendar identifiers, names, colors, access roles, and time zones. For calendars the user explicitly selects as projects, it reads event names, start and end times, event status, free/busy transparency, the current user's attendee response, and recurrence-instance identifiers.

Project Time does not request event descriptions or locations. It does not create, modify, or delete calendars or events.

How data is used

The data is used only to calculate and display scheduled-time summaries inside the Google Calendar sidebar. Event names are used to identify the longest and shortest counted activities. Data is not used for advertising, profiling, AI training, or unrelated purposes.

Storage and retention

Selected calendar identifiers, counting preferences, and the current view are stored in Apps Script User Properties, scoped to the signed-in user. Calculated summaries—including the two activity names displayed as longest and shortest for each project—may be stored in Apps Script User Cache for up to three minutes to improve performance.

Raw event lists are not written to an external database. Preferences remain until the user resets Project Time data. Cached summaries expire automatically and can be cleared immediately with Refresh or Reset.

Sharing and transfers

Project Time has no external server or database and does not sell, rent, or share Calendar data with third parties. Processing occurs within Google Calendar and Google Apps Script, which are Google services governed by the user's agreement with Google.

Security

Project Time uses Google's OAuth authorization, requests read-only Calendar access, and relies on Google Apps Script's user-scoped property and cache services. No method of processing is risk-free, but the add-on minimizes the fields it requests and avoids external data transfers.

Deleting data

Open Project Time in Google Calendar, choose Settings, select “Delete my data,” and confirm. This removes the user's Project Time preferences and clears tracked cached summaries. The user can also uninstall the add-on to revoke access. For assistance, contact franciscoabmendonca@pm.me.

Google API Services User Data Policy

Project Time's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Changes

This policy may be updated when the add-on or applicable requirements change. Material changes will be reflected by updating the effective date on this page.
